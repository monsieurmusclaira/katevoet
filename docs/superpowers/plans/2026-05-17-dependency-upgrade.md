# Dependency Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Astro to 6.4.4 and bring the other dependencies up to their latest safe (minor/patch) versions, with no major migrations.

**Architecture:** One-shot upgrade on `master`. Two `npm install` commands (one for runtime deps, one for devDeps, to preserve dependency types), then the audit's verification gates (build, `astro check`, linkinator, `npm audit`), then a single commit.

**Tech Stack:** Astro 6 (static), MDX, Tailwind 3, DaisyUI 4, Sass, PostCSS.

**Authorship:** commits authored by `monsieurmusclaira` only — **no `Co-Authored-By: Claude` trailer**.

**Spec:** `docs/superpowers/specs/2026-05-17-dependency-upgrade-design.md`
